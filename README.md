# Airbnb Australia Data Entry Project

## Project Overview
Collected and organized Airbnb data from major Australian cities.

## Data Included
- Region / Suburb
- Bedroom Types & Places
- ADR (Average Daily Rate) in AUD
- Occupancy Rates (%)
- Revenue Data (AUD)

## Cities Covered
Sydney | Gold Coast City | Greater Brisbane | Adelaide

## Skills Used
- Data Entry
- Web Research
- Microsoft Excel
- Data Organization & Color Coding

## Tools
- Google Sheets
- Microsoft Excel
